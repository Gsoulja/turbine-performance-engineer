    All values are simulated, including the fix-check cases; no trained model is running yet.
    About the data Turbine positions come from the farm's published coordinates; terrain and imagery are real but baked at about 19 m and 3 m resolution, not live. Specs are placeholders. Wakes are drawn from the same simple model the simulation uses. Real data plugs in through windMonitor.ingest(step), model output through windMonitor.ingestModel(message).

    Model feed

    What the trained model sends in: one message per 10-minute step with a status, cause, explanation, confidence and expected power for each turbine. Whatever the model sends replaces the stand-in rules for that turbine and step. Where it sends nothing, the rules keep running, so the page works while the model is still training.

    Send output

    Local model server

    Runs the frozen curtailment tree on this machine (uv run serve/server.py in the project folder). The page receives only its answers. It answers one question, curtailment, so the steps it flags show as curtailed and every other step keeps the stand-in rules.

    How the page receives it
    • windMonitor.ingestModel(message) from the page or a script; returns { ok, accepted, errors }.
    • Inline with the rows: windMonitor.ingest({ time, turbines: { T04: { …rows, model: { status, … } } } }).
    • window.postMessage({ type: "windmonitor.model", payload: message }, "*") from a parent page.
    • Open the page with ?model=URL to start polling it. A URL on another origin needs CORS enabled.
    • time is the step the output describes (UTC); it must match the row's time to the minute. Send it before that step's rows, or inline.
    • Statuses: normal, stopped, curtailed, low, sensor. confidence is 0 to 1. Text is cut to 600 characters and tags are stripped.
    • The full contract is in MODEL_FEED.md, with an example in model-feed.example.jsonl.

    Add a farm

    The model reads physical signals only: power, wind speed, rotor speed, pitch and nacelle direction. No alarm or status codes and no maker code list are needed, so a new turbine maker works from the first file. Each file is read up to 30 MB.
